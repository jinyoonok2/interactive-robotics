# Historical visual-policy configurations

These recipes describe completed earlier comparisons and are not current pose
experiments. Eighteen were moved out of the active config directory without
changing their bytes. A copy of the retained ten-epoch visual baseline supports
historical paired-config regression checks.

[Manifest](manifest.json) records checksums. The old thirty-epoch no-residual
path is a compatibility symlink because frozen rollout/trainer defaults still
name it. New experiments use the three current recipes documented in
[the config index](../../../configs/README.md).
