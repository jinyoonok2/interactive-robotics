# Research scope cleanup — November 11, 2026

The active plan now covers supplied-GT-pose conditioning in the original visual
policy, followed by shared visual grounding and predicted-pose conditioning.
Replay/tolerance/evaluator experiments are deferred.

`retired_tools.zip` preserves 27 retired scripts, Slurm launchers and dedicated
tests, plus the documentation immediately before this cleanup. Every archived
code member was verified by SHA-256 before its active copy was removed. These
are historical sources, not launchable instructions. Archived document links
refer to their original locations and dates.

[Cleanup manifest](manifest.json) lists exact paths, checksums, generated caches
removed, and legacy helpers retained for queued-job compatibility. No current
training/evaluation source or checkpoint was modified.
